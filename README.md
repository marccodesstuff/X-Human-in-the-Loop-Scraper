# X-Human-in-the-Loop Scraper

Scrapes X/Twitter content while you browse — enabling supervised, human-in-the-loop data collection workflows.

## Origin

Forked from [As-Foretold-Research-Labs/X-Human-in-the-Loop-Scraper](https://github.com/As-Foretold-Research-Labs/X-Human-in-the-Loop-Scraper).

## Use Case

Designed for supervised scraping workflows where a human operator reviews and validates collected data in real time, reducing noise and improving data quality for downstream LLM or analytics tasks.

## Tech Stack

- JavaScript
- Browser automation
